## Finding 2 — Harvest additional-affix distribution is still a model assumption, not independently validated mechanics

The current census reports approximately:

```text
0 additional affixes: 0%
1 additional affix:  ~50%
2 additional affixes: ~50%
```

This matches the simulator's current Harvest generation model. It is useful for validating the analytical model against the simulator, but it does **not** independently establish that real Path of Exile Harvest Reforge Defence produces this distribution.

The analytical model and Monte Carlo simulator currently share the same underlying assumption, so close agreement between them cannot validate that assumption.

### Recommendation

Keep:

```text
GAME-MECHANICS FIDELITY: PARTIAL
```

until the rare-item affix-count behavior for Harvest Reforge is externally/mechanically verified.

Do not change the optimizer just to force a different distribution without evidence. Instead, make the assumption explicit in a mechanics/diagnostics section:

```text
Harvest additional-affix model used by optimizer:
  1 additional suffix: 50%
  2 additional suffixes: 50%
  Source status: UNVERIFIED / MODEL ASSUMPTION
```

Once verified, change the source status and retain the same machinery.

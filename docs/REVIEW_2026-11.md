calculator, done while waiting for the league after Allflame. Findings come from
four parallel reviews (mechanics, solver math, calculator UI, site/pipeline) with

## B. Calculator accuracy — solver

- [ ] **B1. Default "Cheapest" search stops early.** `genericSearch.ts:2201-2202,
  2613-2628, 2337-2353`, `optimizerService.ts:4435-4497`. RECOMMEND defers Harvest
  always and Regal when the target fits a magic item, then stops at
  `FIRST_USEFUL_RETURNED`. Probe (Large shield cluster, ES T1 + Int T1, 30s):
  default 249.76c in 1.8s; FASTEST_WITHIN_COST 195.26c; PROVE 90s 154.08c.
  **Investigated, not fixed.** Tracing the probe target: the cheaper route (regal →
  exalt, scour on failure) only appears once the all-actions graph reaches ~5,000
  states, about 45s in (round at 3,334 states / 21s: still 239.76c downstream; round
  at 5,000 states / 46s: 144.42c). The clean-base search gets `min(10s, 35%)` of the
  budget in RECOMMEND (`optimizerService.ts:4439`), and a full run finishes in ~2s
  of 30s. Two changes were tried and backed out because neither changed the 30s
  answer: an extra all-actions round with the unused budget (+5s, same result), and
  a soft expansion cutoff so a timed-out round isn't discarded (the truncated graph
  solved, but held only 36 more states). The cost is all-actions transition
  generation (~6ms per state); a real fix is expanding deferred edges best-first by
  optimistic bound, or making that generation cheaper. Until then the 30s default
  can't find these routes — "Deep" (60s) with Retry deeper can.
- [ ] **B2. A timed-out round discards its work.** `genericSearch.ts:2228-2263`.
  PROVE at 30s still returns 249.76c.
- [ ] **B3. Lower bounds mix objective units with chaos.** `genericSearch.ts:2927,
  3370`; `optimizerService.ts:3240-3253, 1882-1898, 4770-4783, 3212, 3944`.
  FASTEST run showed lower bound 815.2 vs upper bound 195.26. Pruning effect
  *inferred*.
- [ ] **B4. Unchecking "allow fallback prices" removes the self-fracture restart.**
  `optimizerService.ts:4762, 5088, 5453`; filter `genericSearch.ts:1406-1411`.
  *Inferred.*
- [ ] **B5. Self-fracture always scours.** `acquisitionSynthesis.ts:280-286`,
  `strategyDiscovery.ts:113-124`. Overstates fracture routes. *Inferred.*
- [ ] **B6. Market fractured bases ignored.** `marketFracturedPricesChaos` accepted
  but unused (`optimizerService.ts:2996`).
- [ ] **B7. `unexpandedProbabilityMass` isn't a probability.** `genericSearch.ts:1824`.
- [ ] **B8. Legacy paths** (not wired to UI): `monteCarlo.ts:467,522,562` censoring
